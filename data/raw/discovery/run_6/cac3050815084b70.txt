Sort                        : Remove unnecessary items 2. Set in Order         : Organize items for easy access 3. Shine                     : Clean and maintain the workspace 4. Standardize         : Create consistent procedures 5. Sustain                 : Maintain discipline to follow these practices Need for 5S Create clean and pleasant work place Improve file retrieval time Improve Scrap management Locate the required items Create more working space Improve morale of the employee Launch was done on September 2014 Chairman, Principal and Faculty of TCE participated in the launch Chairman spoke on 5S and beyond Consultant explained 5S concepts People Dr. S. Kanthamani Professor 5S Coordinator skmece [at] tce [dot] edu Vision Clean, safe and organized working environment for quality technical education.
